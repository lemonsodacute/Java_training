## Biên dịch và chạy

Cần JDK 8 trở lên và `java`, `javac` trong `PATH`.
Mở cửa sổ lệnh tại từng thư mục bài tập:

```powershell
chcp 65001
javac -encoding UTF-8 *.java
java Main
```

Mã nguồn dùng UTF-8. Nhập `0` để thoát, ngày theo `yyyy-MM-dd`
và dùng dấu chấm cho số thập phân.
